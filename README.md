# Personal Portfolio Website

This project is a three-page personal portfolio website built using HTML, CSS, and JavaScript[cite: 1, 2, 3, 4, 5, 6, 7]. It showcases my background, skills, and projects, and includes a working contact form[cite: 2, 4, 6].

---

##  Pages

* **Home Page:** Displays my contact information, education history, work experience, hobbies, and visual progress bars for my coding skills[cite: 4].
* **Portfolio Page:** Showcases the software and game projects I have worked on, complete with images and descriptions of my role in each project[cite: 6].
* **Contact Me Page:** Features an interactive form where visitors can send a question about a future project[cite: 2].

---

##  How It Works

### HTML (Page Structure)
* Organizes the website into three connected pages with a top navigation bar and a bottom footer containing links to my GitHub, LinkedIn, and email[cite: 2, 4, 6].
* Builds the contact form using text boxes, checkboxes, and a date picker[cite: 2].

### CSS (Design & Layout)
* Styles the website with a consistent color theme and centers the text and images[cite: 3, 5, 7].
* Arranges the education, contact, and skill sections side-by-side[cite: 4, 5].
* Creates green percentage bars to visually display my skill levels in HTML, CSS, and JavaScript[cite: 4, 5].

### JavaScript (Form Validation)
Checks the contact form before it can be submitted to make sure all information is entered properly[cite: 1]:
* Checks that no required boxes are left empty[cite: 1].
* Makes sure the name only contains letters and the phone number only contains numbers[cite: 1].
* Checks that both email boxes match[cite: 1].
* Makes sure at least one contact method (Text or Email) is selected[cite: 1, 2].
* Checks that the chosen project date is in the future[cite: 1].
* Displays a pop-up summary of all the entered details for the user to confirm, then clears the form once submitted[cite: 1].
